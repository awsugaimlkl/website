# Sponsor and partner logos

Put one logo per sponsor in this folder, named to match the `logo` value in the event's `.md` file. For example, `logo: "acme"` uses `acme.png`.

PNG, SVG, JPG or WebP all work. Logos are shown on a white tile at up to 56 pixels high, so use the version of the logo made for light backgrounds, at least 300 pixels wide. A sponsor without a logo is shown by name.
