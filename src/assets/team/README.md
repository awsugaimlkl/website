# Team photos

Put one photo per person in this folder, named to match the `photo` value in `src/lib/team.js`:

- `kuan-hoong.jpg`
- `spyros-kyriazatis.jpg`
- `hong-wei-chin.jpg`

JPG, PNG or WebP all work. A square photo of about 600 by 600 pixels with the face near the centre looks best, because the site crops it to a circle. Until a file is here, the card shows the person's initials.
