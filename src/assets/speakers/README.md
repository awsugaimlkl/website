# Speaker photos

Put one photo per speaker in this folder, named to match the `photo` value in the event's `.md` file. For example, `photo: "jane-tan"` uses `jane-tan.jpg`.

JPG, PNG or WebP all work. A square photo of about 400 by 400 pixels with the face near the centre looks best, because the site crops it to a circle. A speaker without a photo is shown with their initials.
